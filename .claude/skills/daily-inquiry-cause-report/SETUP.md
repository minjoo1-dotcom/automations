# daily-inquiry-cause-report — 팀원 세팅 가이드

전일자 한도조회 유저수의 전주 동요일 대비 증감을 매체구분(CRM/Paid/Organic)·매체별로 분해해
Slack 원인추적 초안을 만드는 스킬. `/daily-inquiry-cause-report`로 실행한다.

## 사용 전 준비 (각자 1회)
이 스킬은 파일만으론 안 돌아가고, 실행자 계정에 아래가 연결/허용돼 있어야 한다.

1. **MCP 커넥터**: Slack, Google Drive, (선택) Mixpanel. Claude Code에서 각자 연결.
2. **Slack 접근 권한**: `#growth`(C03AG61KVJS), `#growth_internal`(C071PE9G2EQ) 멤버십.
   캠페인명·전주 유입을 이 채널들에서 읽어온다.
3. **대시보드/시트 접근**: 태블로 "매체구분별/매체별 전체 성과(D0)", "타앱한도조회 알림톡" 시트.
   (헤드라인 전사 조회 유저수는 캡쳐에 없어 매번 사람이 한 줄 입력)

## DM 전송 대상
완성 초안은 **실행자 본인 DM**으로 전송된다(하드코딩 아님). Slack MCP의 현재 로그인 사용자
user_id로 자동 해석되며, 본인이 DM에서 확인 후 직접 `#growth`에 올린다.

## 입력물
실행하면 체크리스트가 뜬다: ① 매체구분별 D0 캡쳐 ② 매체별 D0 캡쳐 ③ 전사 조회 유저수 헤드라인
④ 금주 발송상세 캡쳐(유입 100+ 캠페인 전부). 월요일 보고는 금·토·일 3일치.
